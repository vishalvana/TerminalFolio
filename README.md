# VISHAL_VANA Portfolio

A premium developer portfolio built with pure HTML, CSS, and JavaScript featuring a dual-interface experience:

- Terminal Mode for an interactive command-line style portfolio
- Desktop Mode for a modern premium UI showcase

The project combines cyberpunk-inspired aesthetics, smooth animations, and an immersive user experience to create a unique personal portfolio.
